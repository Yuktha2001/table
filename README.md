# Table Project

## 📌 Project Overview

This project demonstrates how to create and structure tables using **HTML**.
It showcases the use of different table elements such as rows, columns, headers, and table styling to organize data in a clear and structured format.

The goal of this project is to understand the fundamentals of **HTML tables** and how they are used to display structured information on web pages.

---

## 🚀 Features

* Structured table layout
* Use of table headers and rows
* Organized data presentation
* Simple and clean HTML implementation

---

## 🛠️ Technologies Used

* HTML

## ▶️ How to Run the Project

2. Open the project folder.
3. Double-click **index.html** or open it in any web browser.

## 🎯 Learning Objectives

* Understanding `<table>` structure
* Using `<tr>`, `<th>`, and `<td>` tags
* Organizing data in rows and columns
* Practicing basic HTML page structure

## 📷 Output

The webpage displays a simple table that organizes information into rows and columns for easy readability.
